# SlideForge UI Design

> 界面设计规范与视觉指南

---

## 1. 设计原则

### 1.1 核心原则

| 原则 | 说明 |
|------|------|
| **内容优先** | UI 服务于 Slides 内容，不喧宾夺主 |
| **即时反馈** | 操作有明确的视觉反馈 |
| **渐进披露** | 复杂功能按需展示 |
| **一致性** | 组件、交互、视觉保持统一 |

### 1.2 设计目标

- 让用户 3 秒内理解当前页面的作用
- 核心操作不超过 2 次点击
- 支持键盘完成所有操作

## 7. 动效规范

### 7.1 过渡时间

| Token | Duration | 用途 |
|-------|----------|------|
| `fast` | 150ms | 按钮 hover、focus |
| `normal` | 200ms | 面板展开、卡片 hover |
| `slow` | 300ms | 页面切换、模态框 |
| `slower` | 500ms | Slide 动画 |

### 7.2 缓动函数

```css
:root {
  --ease-out: cubic-bezier(0.16, 1, 0.3, 1);
  --ease-in-out: cubic-bezier(0.65, 0, 0.35, 1);
  --ease-bounce: cubic-bezier(0.34, 1.56, 0.64, 1);
}
```

### 7.3 常用动效

```css
/* 卡片 Hover */
.card:hover {
  transform: translateY(-2px);
  box-shadow: 0 10px 40px rgba(0, 0, 0, 0.3);
  transition: all 200ms var(--ease-out);
}

/* 按钮 Press */
.button:active {
  transform: scale(0.98);
  transition: transform 100ms;
}

/* 页面进入 */
@keyframes fadeInUp {
  from {
    opacity: 0;
    transform: translateY(20px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}
```

- 正文文字: 至少 4.5:1
- 大标题: 至少 3:1
- 交互元素: 至少 3:1
