# SlideForge 海报系统设计文档

> Markdown → 精美海报，一键生成

---

## 1. 产品定位

### 1.1 核心场景

将 Markdown 内容转换为可分享的精美海报图片，适用于：
- 社交媒体分享（朋友圈、Twitter、LinkedIn）
- 知识卡片（金句、要点总结）
- 活动宣传（会议、发布会）
- 个人品牌（签名档、名片）

### 1.2 设计原则

1. **Markdown 驱动** - 内容即结构，语法即布局
2. **主题丰富** - 不只是换颜色，而是完整的视觉风格
3. **开箱即用** - 默认就好看，无需调整
4. **导出友好** - 高清 PNG，适合各平台

## 2. Markdown 语法与布局映射

### 2.1 基础映射规则

| Markdown 语法 | 海报元素 | 视觉效果 |
|--------------|---------|---------|
| `# H1` | 主标题 | 大号加粗，居中或左对齐 |
| `## H2` | 副标题 | 中号，主题色强调 |
| `### H3` | 小标题 | 小号加粗，分隔内容 |
| `正文段落` | 正文 | 标准字号，舒适行高 |
| `- 列表项` | 要点列表 | 图标 + 文字，间距适中 |
| `> 引用` | 引用块 | 左边框 + 斜体 + 背景 |
| `**加粗**` | 强调文字 | 加粗 + 主题色 |
| `*斜体*` | 次要强调 | 斜体 |
| `---` | 分隔线 | 装饰性分隔 |
| `![](url)` | 图片 | 圆角图片 |
| `` `代码` `` | 行内代码 | 背景色 + 等宽字体 |
| `[链接](url)` | 链接文字 | 下划线 + 主题色 |

### 2.2 特殊语法扩展

```markdown
<!-- 海报元信息 -->
---
theme: glassmorphism
width: 800
author: SlideForge
qrcode: https://slideforge.dev
---

# 标题
```

## 3. 主题系统设计

### 3.1 主题结构

每个主题包含：
- 背景样式（纯色/渐变/图案/毛玻璃）
- 排版系统（字体、字号、行高、间距）
- 色彩系统（主色、强调色、文字色、背景色）
- 装饰元素（边框、阴影、圆角、图标样式）
- 特殊效果（模糊、光晕、纹理）

### 3.2 内置主题

#### 1. 简约白 (Minimal Light)
```
背景: 纯白 #FFFFFF
文字: 深灰 #1a1a1a
强调: 蓝色 #3b82f6
特点: 干净、专业、适合正式场合
```

#### 2. 暗夜黑 (Dark Mode)
```
背景: 深灰 #0f172a
文字: 浅灰 #e2e8f0
强调: 蓝色 #60a5fa
特点: 护眼、科技感、适合技术内容
```

#### 3. 毛玻璃 (Glassmorphism)
```
背景: 半透明白 + 模糊 + 渐变底色
文字: 深色
强调: 紫色渐变
特点: 现代、时尚、适合创意内容
边框: 1px 半透明白边
```

#### 4. 渐变紫 (Gradient Purple)
```
背景: 紫蓝渐变 from-violet-600 to-indigo-600
文字: 白色
强调: 黄色/白色
特点: 活力、年轻、适合社交分享
```

#### 5. 日落橙 (Sunset)
```
背景: 橙粉渐变 from-orange-500 to-rose-500
文字: 白色
强调: 黄色
特点: 温暖、热情、适合活动宣传
```

#### 6. 森林绿 (Forest)
```
背景: 绿青渐变 from-emerald-600 to-teal-600
文字: 白色
强调: 黄绿色
特点: 自然、清新、适合环保/健康主题
```

#### 7. 纸张米 (Paper)
```
背景: 米色 #fef3c7 + 纸张纹理
文字: 棕色 #78350f
强调: 琥珀色
特点: 复古、文艺、适合引用/文学内容
```

#### 8. 霓虹 (Neon)
```
背景: 深紫 #1e1b4b
文字: 白色
强调: 霓虹粉/青 + 发光效果
特点: 赛博朋克、潮流、适合科技/游戏
```

## 5. 技术实现

### 5.1 Markdown 解析

使用 `marked` 库解析 Markdown，自定义 renderer 实现：
- 标题层级样式
- 列表图标
- 引用块样式
- 代码块高亮

### 5.2 主题系统

```typescript
interface PosterTheme {
  id: string;
  name: string;
  // 背景
  background: {
    type: 'solid' | 'gradient' | 'image' | 'glass';
    value: string;
    overlay?: string;
  };
  // 排版
  typography: {
    fontFamily: string;
    h1: { size: string; weight: string; color: string; };
    h2: { size: string; weight: string; color: string; };
    h3: { size: string; weight: string; color: string; };
    body: { size: string; lineHeight: string; color: string; };
    accent: string;
  };
  // 装饰
  decoration: {
    borderRadius: string;
    shadow: string;
    border?: string;
    blur?: string;
  };
  // 元素样式
  elements: {
    hr: string;
    blockquote: string;
    code: string;
    list: string;
    link: string;
  };
}
```

### 5.3 渲染流程

```
Markdown 输入
    ↓
marked 解析 → HTML
    ↓
应用主题样式 → Styled HTML
    ↓
React 渲染 → DOM
    ↓
html2canvas → PNG
```

### 5.4 导出优化

- 使用 `html2canvas` 截图
- 设置 `scale: 2` 保证高清
- 支持自定义宽度
- 文件名包含时间戳
